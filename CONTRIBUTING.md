# Contributing

Thanks for your interest in contributing to AI Workflow Pro projects!

## Reporting Bugs

Found a bug? Please [open an issue](../../issues/new?template=bug.yml) using the bug report template. Include:

- What happened vs what you expected
- Steps to reproduce
- Your environment (OS, version)

## Suggesting Features

Have an idea? [Open a feature request](../../issues/new?template=feature.yml). Describe the problem you're trying to solve and your proposed solution.

## Video playbooks

Repos named `awp-playbook-*` accompany a YouTube video, and the video cannot change. For these repos we accept:

- Corrections (typos, wrong numbers, wrong paths)
- Broken links
- Fixes that keep a prompt working with a newer agent or model

We don't accept pull requests that extend the content beyond what the video teaches. If a prompt didn't work for you, [open a "Prompt didn't work" issue](../../issues/new?template=prompt.yml) with your agent, model and the step you ran.

## Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b fix/short-description`)
3. Commit your changes with clear messages
4. Push to your branch
5. Open a Pull Request

Before submitting:

- Follow existing code style and conventions
- Update documentation for any changed behavior
- Make sure CI passes

## First-Time Contributors

Look for issues labeled [`good first issue`](../../labels/good%20first%20issue) — these are specifically picked for newcomers.

## Code of Conduct

All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
