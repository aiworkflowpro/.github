# .github

Default community health files for [AI Workflow Pro](https://aiworkflowpro.com) open source projects.

Files in this repository automatically apply to all `aiworkflowpro` repositories that don't have their own versions:

- **Code of Conduct** — Contributor Covenant
- **Contributing Guide** — How to report bugs, request features, and submit PRs
- **Security Policy** — How to report vulnerabilities
- **Support** — Where to get help
- **Issue Templates** — Bug reports and feature requests (YAML forms)
- **PR Template** — Pull request checklist
- **Funding** — Sponsor button configuration

Learn more: [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)
